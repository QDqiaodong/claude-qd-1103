# 奶茶饮品店 · 原料库存与配方出单

奶茶饮品店的原料库存、配方出单、会员积分与出杯退款管理。后端 Spring Boot + JPA，前端 Vue 3 + Element Plus（焦糖主题、顶部标签页导航）。

## 启停

```bash
sh start.sh     # 启动（后端 + 前端 + MySQL）
sh stop.sh      # 停止
```

## 模块

- 原料库存：茶底 / 奶 / 小料 / 糖浆 的库存与启用停用
- 配方出单：勾选小料 + 右侧抽屉填份数生成配方（小料用量用 `@ElementCollection Map` 承载）
- 会员：手机号唯一，消费累加积分并按阈值升级（银卡 ≥ 500，金卡 ≥ 2000）
- 出杯记录：按配方明细汇总金额，仅「已出杯」可退款并回退积分

## 出杯库存履约闭环

- **明确扣减口径**：每出一杯消耗 1 个库存单位的茶底（`Dict.BASE_TEA_PER_CUP`），
  小料按「配方份数 × 杯数」计算；多配方、重复明细先合并再汇总本单原料需求。
- **提交前预览**：出杯页实时展示预计金额、积分与逐原料预计扣减/当前库存，
  标出不足、已停用、引用失效原料；预览仅供提示，成交以提交时服务端事务内最新库存为准。
- **原子下单**：`POST /api/cup-orders` 在一个数据库事务内按 id 升序对原料行加写锁
  （并发出杯串行、防死锁），锁内二次校验库存/停用/引用后才扣库存、加积分、落订单与明细。
  任一原料不满足则整单回滚：不产生订单、不扣任何库存、不增加积分。
- **扣减快照**：每笔订单的实际原料扣减逐行写入 `cup_order_deduction`
  （原料 id 锚点 + 名称/类别/单位/数量快照），之后配方或原料如何编辑都不改变历史消耗。
- **退款回补**：`POST /api/cup-orders/{id}/refund` 先锁订单行做状态判定
  （仅「已出杯」可退、只执行一次），按快照精确回补原料并回退原积分；
  重复点击 / 并发退款只有一个事务成功，不重复回补。
- **历史旧单**：功能上线前无快照的旧出杯记录仍可退款、仍回退积分，但不凭空回补库存，
  列表中以「未扣减 / 未回补」与备注明确标识。
